3. Handle old late acquisitions resolving to the exact same proxy as a new operation. Avoid unbounded permanent bookkeeping after settlement; reader destruction remains authoritative teardown.
4. Correct current prose that equates caller settlement with underlying-work completion; document actual reuse/cleanup behavior.

Acceptance criteria:
