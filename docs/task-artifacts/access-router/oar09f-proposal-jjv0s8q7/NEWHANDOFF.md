- Batch is **one operation**: validate controls/receiver, capture effective initialized actor/model/catalog/config/scope/output policy once before await/callback, then own **all** row sources before the first field predicate. Duplicate IDs/references do not share function decisions or native leaves. Embedded children derive only locally. One failure/publication owner closes/drains; no partial batch or callback-side-effect rollback.
- Proposed new fixed bounds: **1,000 outer positions / 200,000 aggregate structural-work units / 16 MiB cumulative staged/copied payload**, on top of separate existing per-row source/fact/view/output/native bounds. Dense ordinary readonly Arrays only, no iterator consumption; strict control/proxy/getter/symbol/sparse/extra/cycle admission. Empty arrays still validate and capture policy; no row work.
- Existing request/runtime worker and hook limits bound batch row work; field order/short-circuit retained, output indexed in input order. Callback-body failure denies its field; structural/native/budget poison rejects whole batch with controlled 400 after drain, including caught poison. Original-request `this` and closure/native/external-state non-promises remain explicit.
- Only call preparation is amortized. A 100×24 **all-function untimed control** must retain 2,400 callbacks / 100 source admissions and stages. Actual H3-global uses **string/global rules, zero function callbacks**; its 2,400 business-field checks cannot be turned into skipped checks. Promise/binding/actor-map counts must be measured later, not assumed. Current evidence does not prove every residual cost irreducible.
- No document hooks, virtuals, row checks, related/correlated-provenance recovery or library DB I/O. Negative EMPTY predicates are not document facts; metadata/grants do not supply current document authority. Preflight protects later rows from subsequent field callbacks, not arbitrary effects of trusted native/hydration normalization or external caches/DB changes.

`FilteredOutput<T>` deeply makes string fields optional, preserves array containers with conservative omitted/null elements, maps string-keyed Maps to records, and preserves canonical Date/RegExp/Buffer base types. Other BSON values, hydrated roots and deep type recursion fall back to `unknown`, not unsound nested-required/native assertions. Readonly annotations are not a native freeze or output capability.
