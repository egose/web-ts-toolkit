### Published weaker contract

- Both new optional booleans are independent/default false/literal server true.
  False is off; true plus **all four matching** document/output/nested comparison
  and initial-copy skips is active; any missing prerequisite leaves it dormant.
  Never enables prerequisites or changes the original six/two/eight groups.
- Genuine LIST/READ capture precedes hooks/awaits. READ-to-list retries stay READ;
  authenticated descendants inherit origin capture, not live target flags;
  independent callback calls own their origin. Rollback changes new calls only.
  Explicit false beats defaults; undefined restores inheritance. Presence in
  service/public/default/policy/helper/include/populate/`$$sq` controls rejects;
  same-named business data is inert. Writes/write-derived output/dedicated
  subdocuments/fresh raw helpers remain strict.
- Actual active ordinary rows borrow lean source/hook input and ordinary grants,
  share grants per field/read/owning embedded child, use shallow diagnostic contexts
  and reused captured config/scope views. No trusted stage snapshot or current
  descendant identity/snapshot walks. Cheap root/call/stage/request/runtime/model/
  name/scope/access bindings, original actor/evaluators, modern mandatory root/target
  hooks, target gates, selected/denied data and metadata/virtual semantics remain.
- Handle lookup is **issued-document membership, not reachability**. Removed
  originals can remain discoverable, replacements gain no handle, and exact-root
  helpers filter changed descendants with stale memo/shared grants after rollback.
  No public issuer/certificate/private helper/type/marker is exported or shipped.
- New selected algorithms retain 20,000 visited-slot/issued-root and depth-100
  budgets/safe descriptor writes/cycle errors, **not full unvisited source/grant/
  context bounds**. Copied/trusted rows can coexist; copied roots/grants/value
  fallbacks remain, without hook reruns. Active config is not every-row zero-copy.
  Snapshot native/BSON wire/equality passes are gone, not every native observation:
  hydration/selected natives/getter stable-base and per-getter views/return staging/
  private argument-four isolation/JSON normalization remain.
- Mutation/stale decisions/descendant replacement/fewer native observations can
  **turn denial into allowance**. Existing eight-option retained-copy/graph promises
  are explicitly qualified with the matching new flag off/dormant. The old fusion
  withdrawal notice and all withdrawal fixtures are preserved. Experimental
  performance-first: benchmark your workload; no universal gain or v0.51.0 parity.
