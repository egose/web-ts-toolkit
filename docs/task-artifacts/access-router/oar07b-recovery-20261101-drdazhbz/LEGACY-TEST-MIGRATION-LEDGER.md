## Deliberate contract changes

- Removed handles/context snapshots/rich grants do not get adapters. Already-filtered DTOs remain application DATA; scoped explicit server output grants are separate fresh helper inputs. Empty-fact negative predicates are not current-document proof; no hidden reads or doc hooks were added.
- Output/doc-permission/decorator contexts are frozen allowlisted diagnostics; mutation lifecycle contexts and live persisted documents retain their mutable role. Hook argument views, actual DB reads and stored values replace assertions against removed output aliases.
- Current private configuration readers share owned preparation; tests no longer mutate that private store as if it were an application exposure. Native values are owned at capture and detached at actual receiving exposure.
- A descendant-only selected scalar produces no scalar disclosure (null is permitted selected shape); raw helpers still omit unsupported scalar ancestry. Include presentation collisions do not replace original hook-input facts.
- Unsupported one-argument model-router setup is corrected to the existing typed overload. Default setter preflight rejects invalid defaults synchronously/atomically. Public malformed authority rejects before denied-route work.
- The 10,000 grouped-key bound is retained alongside—not instead of—the 20,000 selected/source bound; its HTTP test observes default source rejection and separately succeeds with a trusted private join whose output value is denied/unselected.
